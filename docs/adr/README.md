# CityPulse Architecture Decision Records

Architecture Decision Records (ADRs) document significant technical decisions
made during the design and evolution of CityPulse.

## Why ADRs Exist

Architecture changes over time.

The purpose of an ADR is to preserve:

- the problem being solved
- the constraints at the time
- alternatives considered
- the selected decision
- the reasoning behind it
- accepted trade-offs
- future consequences

## Status

An ADR may be:

- Proposed
- Accepted
- Deprecated
- Superseded

Accepted ADRs are not rewritten when the architecture changes.

A new ADR should supersede the previous decision.
